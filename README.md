Sistema de Gerenciamento de ONG de Animais 🐾

Este projeto consiste em um sistema de console desenvolvido em C++ para o gerenciamento de animais em uma ONG. Ele permite o cadastro detalhado de animais, a organização por tipos de cuidados necessários e o controle de disponibilidade para adoção.

Projeto desenvolvido como parte do curso de Desenvolvimento de Software Multiplataforma na Fatec Porto Ferreira.

🚀 Funcionalidades
O sistema oferece uma interface de menu interativa com as seguintes opções:

Cadastrar Animal: Registro completo incluindo nome, idade, raça, cor, porte, personalidade e sexo.

Categorização de Cuidados: No momento do cadastro, é possível definir a prioridade do animal entre:

Veterinário

Alimentar

Abrigo

Listagem Geral: Exibição detalhada de todos os animais no sistema, utilizando polimorfismo para mostrar os cuidados específicos de cada um.

Gestão de Adoção: Ferramenta para alterar o status de disponibilidade de um animal específico para "Disponível".

🛠️ Tecnologias e Conceitos Utilizados
Linguagem: C++

Paradigma: Orientação a Objetos (POO)

Herança e Polimorfismo: Classes especializadas para diferentes cuidados que herdam da classe base Animal.

STL (Standard Template Library): Uso de std::vector para gerenciamento dinâmico de memória.
